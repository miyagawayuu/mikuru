# Mikuru Vue-like ToDo Example

This example demonstrates a small Vue-like ToDo app built with the Mikuru runtime `ref`, `computed`, and `effect` APIs.

Run from the repository root:

```bash
npx vite --config examples/mikuru-vue-like/vite.config.ts
```

The repository root also provides a shortcut:

```bash
npm run dev:mikuru-vue-like
```

Open http://localhost:5175
